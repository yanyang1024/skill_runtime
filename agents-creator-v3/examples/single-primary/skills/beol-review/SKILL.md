# BEOL 数据复核

输入：数据文件或表格、指标与单位、用户提供的阈值和比较范围。输出：规则来源、逐项证据、异常列表和缺失信息。

1. 读取实际材料，核对指标、单位和上下界是否明确。关键口径缺失时列出缺口，不凭领域经验补阈值。
2. 按输入规则比较数值；区分越界、缺失和正常。未提供时间与对照信息时，不推断趋势、因果或处置方案。
3. 每项结论附数据行／记录编号和规则来源。无法读取或数据互相矛盾时说明阻塞项。
4. 核对纳入范围与条目数量，确保没有把缺失值当零、把未检查记录当正常。会话中输出简洁结果，不写文件。
