# 交互场景常见踩坑清单

从上游 OpenMAIC 生成 prompt 的"常见 bug / 检查单"部分提炼，面向 MAIC-Lite DSL 改写。产出前逐条自查。

## 状态机与重置

- **reset 必须真正复位**：最常见的 bug 是按钮文字变成"重新开始"但点击后不复位。用一个独立的 `resetSimulation()`，把**所有**状态变量（位置、速度、计时、running/ended 标志）恢复到初始值，再重绘。
- **状态机要清晰**：用明确的 `idle / running / paused / ended` 状态变量驱动主按钮行为；按钮文案必须反映点击后会发生什么（启动 / 暂停 / 继续 / 重新开始）。不要出现一个按钮仅凭文字分支做不同的事。
- **`ended` 与 `running` 分开跟踪**：模拟到达边界/结束时置 `ended = true`，否则会出现"卡死"或按钮无响应。

## 动画可见性

- **点击"启动"后必须有肉眼可见的运动**：对象移动/旋转/变色，而不是只有计时数字在变。看不见动 = 用户以为坏了。
- 旋转类对象要真的 `ctx.rotate()`；动画幅度要明显，不要微妙到看不出来。
- 多重反馈叠加：位置变化 + 计时更新 + 颜色/高亮 + 状态指示。
- 动画一律用 `requestAnimationFrame`，每帧清屏，渲染循环里不要反复创建对象。

## 布局与视口

- **针对 1280×720 逻辑视口设计**：宿主负责 scale 缩放，不要写依赖窗口实际尺寸的不可缩放布局，也不要用固定像素把内容撑出视口。
- **控制面板不得遮挡画布/游戏对象**：为 HUD/控制区预留安全边距（如顶部 100px、底部 200px），对象坐标换算在剩余可玩高度内进行；控制区占比不超过约 30% 高度。
- **canvas 尺寸用 ResizeObserver 或 resize 事件适配容器**，每帧按容器实际尺寸绘制，不要写死像素。
- 数值显示用等宽字体并带单位。

## 触控与交互

- 触控目标最小 **44×44px**；滑块拇指至少 24px。
- 按钮加 `touch-action: manipulation` 防双击缩放；canvas 自定义手势用 `touch-action: none`。
- 控件加 ARIA 标签；键盘支持（如空格开始/暂停、R 重置）。

## game 专属

- **公平开局**：前 3-5 秒无失败条件；默认参数下至少能存活 10 秒；对象初始位置远离危险区；物理参数先验算（如轨道速度 ≥ sqrt(GM/r)）再写进初始值。
- **游戏不是换皮选择题**：玩家必须操控某个影响结果的东西（调推力、拖拽、时机判断），成功取决于操作而不只是知识。
- 关键的开始按钮用内联 `onclick`（脚本前面出错也不会点不动）；被 onclick 调用的函数必须挂在全局（DOMContentLoaded 内定义的要赋给 `window`）。
- 初始化流程保持简单直接：隐藏开始遮罩 → 置状态 → 初始化关卡 → 启动 game loop；不要在启动链里塞异步依赖。
- 自定义 CSS 优先，不要依赖外部 CSS 框架的运行时编译。

## diagram 专属

- 边要连到**节点边缘**而非中心：按方向（水平/垂直取主导分量）从节点边界起止，箭头再留偏移量。
- 首屏至少第一个节点可见；所有节点连通，无孤儿节点。
- 节点给稳定 id（`node-{id}`）；避免 hover 变换与点击态冲突造成抖动。

## code 专属

- **只有 JS 可在浏览器内执行**（其他语言只演示不执行——离线红线禁止 CDN 上的运行时）。
- JS 执行用 `try/catch` 包裹，错误输出到 `#output` 面板而不是 alert。
- 编辑区与输出区不重叠；测试用例有明确的通过/未通过指示；提示逐条渐进揭示。
- 处理 `SET_WIDGET_STATE` 时先判断编辑器对象是否存在（`typeof editor !== 'undefined'`），textarea 兜底用 `#code-input`。

## 输出前检查单

- [ ] 恰好一个 `<!DOCTYPE html>`、一个 `</html>`，无重复段落
- [ ] 零 http(s) 外链、零网络请求、零 localStorage/cookie
- [ ] reset 恢复全部状态变量
- [ ] 按钮文案与行为一致，状态机转移明确
- [ ] 动画肉眼可见
- [ ] 控制区不遮挡内容，对象不被 UI 覆盖
- [ ] 触控目标 ≥ 44px
- [ ] 关键元素按命名约定给 id/class
- [ ] postMessage 监听已内嵌
- [ ] `python3 tools/course_validate.py --course <dir> --scene <id>` 输出 errors == 0
