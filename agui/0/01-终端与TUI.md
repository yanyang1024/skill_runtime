# 阶段一：终端、CLI 与 TUI——表达、组合和状态

## 1. 技术条件与界面形式

早期交互受终端显示、输入设备、计算资源和远程接入条件限制。字符不仅是展示内容，也可作为命令和数据的载体。这里区分三类常被混用的交互：批处理提交作业；CLI 输入命令、接收输出；TUI 在终端中构造菜单、列表、窗格和持续更新的状态。

Unix 的历史材料将管道与工具箱式程序组合联系起来，并强调文本流的通用接口价值。这个事实说明一种可组合接口如何影响工作方式，不证明所有系统都应该使用文本。[Bell Labs 历史材料](https://www.nokia.com/bell-labs/unix-history/philosophy.html)

| 形式 | 用户动作 | 系统的可见对象 | 优势 | 代价 |
|---|---|---|---|---|
| 批处理 | 提交作业与参数 | 作业、输出、退出结果 | 重复执行、资源调度 | 反馈延后、调试困难 |
| CLI | 编写命令与参数 | 命令、路径、流 | 精确、组合、可记录 | 语法和环境知识负担 |
| TUI | 导航列表、切换窗格、快捷键 | 当前选项、文件、状态 | 字符环境下提高可发现性 | 焦点与布局依赖，仍有学习成本 |

TUI 是字符环境中的交互设计，并不等于给 CLI 加一个漂亮边框。它把部分记忆负担改为识别，但常常牺牲直接脚本化能力。一个全屏程序对于人可能更容易，对于自动化程序却更难，除非同时提供稳定命令或数据接口。

## 2. 当时 UI 在解决什么

第一，压缩表达：专家可以用短命令完成长操作序列。第二，组合：将多个工具接成流程。第三，复现：把一次成功操作保存为脚本。第四，远程和低资源可用性。

这些优势有前提：输入输出约定明确，环境相对可控，用户理解工具含义。即使纯文本，输出也可能含分页、颜色控制码、非结构化警告、时变字段；“模型能读”与“程序能稳定消费”是两回事。

## 3. 对 Agent 的历史类比

LLM 可以降低命令发现和语法记忆成本，因此 CLI 对非专家可能变得更可达。模型也容易生成脚本，将一次目标转成多步操作。但自然语言解释器带来新的不确定性：它可能选错命令、误判路径或扩大操作范围。

由此可提出两条并行路线：

- 给现有命令增加 JSON 输出、退出码、帮助文档、预检和效果预览，方便 Agent 调用。
- 给人保留 TUI 的概览与快捷键，Agent 通过稳定接口操作同一状态，而不是模仿按键。

**假设 A**：未来一部分“Agent UI”会是优秀 CLI 的重新发现，而非完全新的视觉范式。适用条件是任务可组合、文件是主要产物、工具接口成熟。反例是空间编辑、审美判断和可视化探索。

**假设 B**：语言入口会让命令行成为业务人员可用的后台，但前台仍需要参数检查和结果预览。若模型的错误解释让用户无法判断，则隐藏语法也可能隐藏危险。

## 4. Shortcut 的两种含义

键盘 shortcut 压缩人的操作路径；工作流 shortcut 压缩机器的执行路径。二者可以共享一个操作语义，例如“导出本次筛选结果”，但不必共享物理按键。

可尝试把成功对话转换成有名称的可复用动作：第一次用语言表达，第二次点击动作卡片，熟练后快捷键调用。沉淀时应保留参数、输入范围和验证规则，而非仅保存上次的文本聊天。否则它只是带有隐含上下文的宏。

## 5. 不宜直接套用的历史经验

管道处理的是明确格式的数据流；Agent 的自然语言交接可能丢失约束。脚本通常在同一环境中复现；Agent 可能每次检索和计划不同。命令退出成功也不等于业务目标达成。

因此“语言就是新 shell”可以作为启发，但需要追问：新的标准输入是什么？标准错误是什么？产物如何传递？失败由谁判断？哪些步骤具有幂等性？

## 6. 一个开放设计场景

用户说：“比较两批工艺数据，列出值得复查的异常。”

可能的界面：左边是可编辑的输入对象和口径；中央是差异表；底部是工作日志；用户点某一行后说“只追这一项”。Agent 通过对象 ID 得到选择范围，调用分析工具；人可查看实际参数和结果。终端可以是开发者的视图，业务人员看到同一任务的表格视图。

值得验证：最节省时间的是自然语言、表格批量选择，还是预定义命令？语言是否只需要负责开始和异常处理？

## 7. 继续头脑风暴的问题

1. 能否建立面向 Agent 的“命令可发现性”，并且避免一次加载所有工具说明？
2. TUI 的高信息密度能否启发 Agent 工作台，而不把开发者日志推给业务人员？
3. 一次成功操作何时值得固化为 shortcut？用户本人是否能理解和修改它？
4. 能否用稳定产物连接阶段，让 Agent 的上下文保持短小？
5. Agent 取消后哪些进程和副作用仍在发生？界面怎样表达这种差别？
