## 关键行为已经验证

- 表单可独立计算统计；模型填写建议不自动提交，也不修改未明确要求的字段。
- 建议生成后人工再修改表单，旧建议不能直接覆盖新字段。
- 活跃用户按完整范围去重；工具失败率使用总失败数与总调用数计算。
- 模糊目标进入澄清状态；用户确认后才执行统计。
- 草稿与当前报告分开；采纳、丢弃、继续修改和 Markdown 导出可操作。
- 人工保存会提升版本；旧草稿采纳被前后端拒绝。两个同版本写入只有一个能成功。
- 保存请求返回期间继续输入的内容保留为未保存编辑，后续可基于新版本再次保存。
- 停止执行后不产生迟到草稿；服务重启时将活动任务标记为中断，保留报告。
- 刷新页面可恢复浏览器会话内的任务与报告。
- 未注册工具及伪造的统计标识不能创建有效报告；工具与模型轮次有预算。
- Responses 严格输出使用 `text.format`；函数定义扁平化；工具结果按 `call_id` 回传。
- 工具循环保留整个 output，包括 reasoning 项；没有仅保留文本造成断链。
- 模型服务认证失败显示错误，不静默退回演示规则；服务端 Key 不出现在配置和任务响应中。
- HTML 字符串按文本渲染；报告中的 `<img …>` 不会成为可执行页面元素。
- 两套界面在手机宽度下没有页面水平溢出。

## 这些验证没有证明什么

演示模式约半秒的统计流程不是模型延迟测量。协议模拟证明应用能够处理约定结构，不证明每家服务商都兼容，也不证明模型能够稳定保留人工补充或作出高质量判断。

这个原型没有进行生产负载、企业身份、多租户权限、持久任务队列或真实业务效果验证。它验证了两种交互结构的运行路径，可用于下一步接入真实数据与模型的比较试验。
