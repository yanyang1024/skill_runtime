## 4. 推理能力影响因素与误差容忍度（对应模型问题 5）

用户问题 5 包含两问：推理时影响大语言模型（large language model, LLM）推理能力最大的因素是什么；相对图像分类模型，LLM 是否对误差容忍度更高。本章依次给出部署侧敏感度排序（4.1）、与卷积神经网络（convolutional neural network, CNN）的分通路对比（4.2）、NAND 存内计算（compute-in-memory, CIM）的器件级噪声证据与缓解组合（4.3），并在 4.4 节对"LLM 容忍度更高"的预设给出专家判定。结论先行：该笼统预设不成立——权重通路上 LLM 的误差容忍度不低于甚至高于 CNN，激活与键值缓存（key-value cache, KV cache）通路上 LLM 显著更脆弱，且评估指标本身会改变结论方向。对 NAND CIM 这反而是结构性利好：模拟乘加（multiply-accumulate, MAC）噪声主要落在容忍度最高的权重通路。

### 4.1 影响 LLM 推理能力的因素排序

#### 4.1.1 权重 vs 激活 vs KV cache 的敏感度排序；激活 outlier 是第一约束

训练侧决定基线能力——Chinchilla 标度律表明参数与数据需等比扩展，70B 的 Chinchilla 靠 4 倍训练数据击败 280B 的 Gopher [^616^]；但"推理时"的精度损失由部署侧因素决定：模型冻结后，关键在于量化/噪声落在哪条通路。多源证据收敛于同一敏感度排序：**激活（outlier）> KV cache（Key 显著大于 Value）> 权重**；层维度上首/末层与注意力（attention）先于中间前馈网络（feed-forward network, FFN）受损 [^613^][^614^]（层内细粒度证据见第 3 章，本章聚焦通路维度）。

激活是第一约束。SmoothQuant 的核心观察是"权重易于量化而激活不然"：朴素 W8A8（权重与激活同为 8-bit）把 OPT-175B 的平均精度从 71.6% 打到 32.3%（接近随机），而同样 8-bit 的仅权重量化几乎无损 [^604^][^606^]；ZeroQuant-V2 的结论（经综述转引）进一步指出"激活量化普遍比权重量化更敏感，在 >10B 模型上尤甚" [^613^]。机理是系统性激活 outlier——规模超过 6.7B 后大幅值通道必然涌现 [^604^]，且误差的"落点"远比"总量"重要：LLM.int8() 实验显示，将 outlier 特征置零使验证集困惑度（perplexity, PPL）恶化 600–1000%，置零同数量随机特征仅恶化 0.1%，破坏力相差 3–4 个数量级 [^606^]。KV cache 内部，Key 远比 Value 敏感：QuaRot 消融（Llama-2-7B，WikiText-2，FP16 基线 PPL 5.47）中 K4V2=5.75 而 K2V4=8.06 [^609^]；KV-AdaQuant 在同预算下 4bit-K+2bit-V 得 75.2% 精度，反过来 2bit-K+4bit-V 仅 54.7%，原因是 Key 矩阵谱范数更大、量化误差被放大 [^610^]。

模型规模与训练程度是容忍度的两个调节变量，方向相反：GPTQ 在 175B 上 4-bit 仅损 ≤0.25 PPL，"更大的模型普遍更容易量化" [^601^]；而量化诱导退化（quantization-induced degradation, QiD）标度律（1500+ checkpoint）显示训练 token 越多退化越重，并预测 100T token 训练的未来模型低比特量化将"不可取" [^617^]，Scaling Laws for Precision 与过训练模型的高斯扰动实验同向——固定扰动幅度下 PPL 退化随训练 token 数单调上升 [^618^][^619^]。对 NAND CIM 的含义：误差预算应优先分配给激活/KV 通路（尤其 Key 与首末层），权重通路是模拟噪声最安全的落点。

### 4.2 LLM 相对图像分类的误差容忍度

#### 4.2.1 通路分裂结论：权重通路容忍度≥CNN（GPTQ 175B@4bit 损 ≤0.25 PPL；IBM Nature Comm. 2023）

权重与器件非理想性维度上，Transformer 系模型明确占优。IBM 在 Nature Communications 2023 的研究对 11 个 DNN 负载施加统一模拟存内计算（analog in-memory computing, AIMC）非理想性模型并做硬件感知（hardware-aware, HWA）训练：BERT transformer 与全部 LSTM 负载达到 >99% iso-accuracy，而 CNN 普遍掉点、最多 3.6%（DenseNet-121 归一化精度仅 85.8–96.4%）[^621^]；IBM 官方博客将其总结为"循环网络普遍表现很好，卷积网络通常最具挑战" [^622^]。医学影像对比同向：Swin U-Net（transformer）在 analog-aware 训练下 Dice 仅降 <0.04，金字塔 CNN 降 0.15–0.22 [^626^]。权重数值精度侧，现代补偿方法已把 4-bit 做到近乎无损（GPTQ 175B 损 ≤0.25 PPL [^601^]、AWQ Llama-2-7B 约 0.1 PPL [^602^]），k-bit 推理标度律甚至论证 4-bit 是 3–16 bit 区间的最优精度 [^605^]。还需区分误差性质：量化误差是确定性的，而 AIMC 噪声随机、零均值、遍布所有权重——Nature Communications 2020 对相变存储器（phase-change memory, PCM）的研究指出，这一区别使注入高斯噪声训练成为天然对策，ResNet 经噪声训练后可恢复到接近软件精度 [^623^]。

#### 4.2.2 激活/KV 通路显著更脆弱：朴素 W8A8 使 OPT-175B 71.6%→32.3%；2-bit Key 即崩溃

激活维度结论反转。SmoothQuant 引言明确指出："与 CNN 或 BERT 等较小 transformer 不同，LLM 的激活难以量化；规模超过 6.7B 后系统性 outlier 必然涌现" [^604^]。CNN 的 INT8 后训练量化（post-training quantization, PTQ）自 Jacob et al. 2018 起已基本解决 [^606^]；LLM 的 W8A8 却必须配合 outlier 处理，W4A4 至今只有旋转类方法（QuaRot/FlatQuant/SpinQuant）能稳住 [^611^]。KV cache 则是 CNN 根本没有的脆弱面：朴素 int2 量化使 PPL 爆炸至 573–100870 [^608^]，即使专门设计的 KIVI 2-bit 也有最高 2% 精度损失 [^632^]，而 2-bit Key 直接崩溃（QuaRot K2V4=8.06 [^609^]）。表 4-1 按通路汇总量化与噪声敏感性实测数据。

**表 4-1 LLM 各通路量化/噪声敏感性实测汇总（2020–2026）**

表 4-1 有三点读法。第一，同一位宽落在不同通路命运截然不同：8-bit 落在权重上几乎无损（GPTQ/AWQ 行），落在激活上却足以让 175B 模型退回随机水平（朴素 W8A8 行）——"几位量化"离开通路语境没有意义。第二，方法学差距即容忍度差距：朴素方法与补偿方法在 3-bit 权重上的差异是"完全崩溃"与"损 0.3–0.6 PPL"之别，说明权重通路的脆弱主要来自朴素映射而非信息论极限，模拟硬件配套补偿/训练后即可利用这一余量。第三，未经适配的 decoder-only LLM 在 6.7% 权重高斯噪声下掉点超过 40 个百分点 [^624^]，与 4.2.1 的"transformer 耐噪"证据看似矛盾——调和关键在于 BERT 是经 HWA 训练的 encoder，而 LLaMA 是自由长链生成的 decoder-only 模型，自回归把单点误差放大为路径漂移，这正引出 4.2.3。

#### 4.2.3 自回归长链推理比 PPL 先崩；仅用 PPL 评估会系统性低估噪声损伤

自回归生成对噪声同时存在"自纠错"与"漂移放大"两副面孔。纠错面来自离散 token 的 argmax 余量：只要 top-1 与 top-2 logit 的间隔不被噪声翻转，输出即不变，概率分布的偏差还可被采样策略纠正 [^631^]。漂移面是经典的曝光偏差（exposure bias）：训练用 teacher forcing、推理用自身输出，误差逐步累积、长程生成尤甚 [^630^]。低比特实测表明"长链推理先崩"：4-bit 权重在 R1-Distill 上近乎无损，3-bit 在 LiveCodeBench 掉 >7%；KV cache 4-bit 无损、3-bit 严重受损，且"退化在长回答的困难任务（AIME-120、LiveCodeBench）上最显著" [^611^]。机制上，量化模型与 FP 模型的分歧集中在高熵（低 margin）位置——KL 散度与 next-token 熵的相关系数 ρ=0.92——噪声在这些位置把采样推向"Wait/But"分支，引发过度思考与路径漂移 [^612^]。基准层面，PPL 几乎不变时下游能力已显著下降（LLM-KICK [^628^]）；4-bit 量化下 workflow/tool-use 仅掉 1–3%，真实 agentic 场景却掉 10–15%（ACBench [^629^]）。对 NAND CIM 的直接含义：用 teacher-forced PPL 验收硬件噪声会系统性低估损伤，验收集必须包含自由生成的长链推理任务（GSM8K/AIME/长上下文检索）——LLaMA-3.1-8B 的模拟噪声实验同样显示推理任务（GSM8K 67.6→38.0）比知识问答掉得更狠 [^624^]。

### 4.3 NAND 硬件噪声证据与缓解手段

#### 4.3.1 Shim 2022：开态电流 2–3.5 nA 波动使 CIFAR-10 掉约 5pt；产品级要求 σ<2.5 nA

器件级核心证据来自 Shim（JSTS 2022）对 3D NAND string 电流变化三大来源（retention、温度、编程图样依赖）的仿真 [^634^]。温度方面：多晶硅沟道晶界阻碍电子漂移，400K 时电子迁移率比室温高 30%，无温度补偿时 310K 以上精度显著下降。图样依赖方面：32-WL string 中即使选中 WL 的 64 个 cell 阈值完全一致，未选 WL 的随机编程图样仍引起擦除 cell 阈值 −1V~0V 波动与开态电流 2–3.5 nA 波动，使 CIFAR-10 推理精度降至 84.5%、较无波动情形掉约 5 个百分点；可察觉退化的阈值为擦除 cell 阈值偏移 >0.25V 或温升 10 度 [^634^]。须注意该实验负载是 CNN 而非 LLM——恰说明即便容忍度较高的 CNN，nA 级开态电流 σ 也造成约 5pt 掉点；与 4.2 节联读，LLM 权重通路预计类似或更耐受，激活/KV 通路需重点防护。同组系统级工作进一步区分噪声类型：随机电流变化可经输入映射方案吸收，系统性 drift 才是主要威胁；其 3D NAND CIM 在 8-bit 推理下芯片面积仅为 SRAM/RRAM 方案的 17–24%、能效 1.9–2.7 倍 [^636^]。

LLM 级产品证据在 2025–2026 年补齐。物理学报 2025 对产品级 3D NAND CIM 芯片做行为级仿真（GPT-2 124M/355M）：维持系统级可靠性要求开态电流分布 σ<2.5 nA，且 INT8 模式下"量化误差是精度的主要瓶颈" [^639^]——INT8 量化本身已接近精度预算极限，留给模拟噪声的余量很小。NVLLM（2026）指出 NAND 读扰动使原始误码率（raw bit error rate, RBER）升高、推高 PPL 并降低精度，因此在架构内集成 ECC 单元、对 INT8 权重注入随机位翻转评估鲁棒性 [^633^]；读扰动 RBER 随读次数增长，且 P/E 磨损以近似二次方速率放大扰动斜率 [^637b^]。flash 老化侧，WISER 实测 16-bit 定点权重在 16K P/E、1e5 次读扰动、1e8 秒 retention 下分别使 VGG-16 掉 17.09%/5.96%/10.15%，位翻转避错后全条件压至 <0.79% [^637^]。

#### 4.3.2 缓解组合：噪声感知训练/LoRA 补偿 + outlier FP16 冗余 + ECC/温补

提高容忍度的方法谱系已有实测支撑，按作用层分为五类组合使用（表 4-2）。

**表 4-2 NAND CIM 精度损失缓解手段与实测效果**

| 作用层 | 手段 | 代表工作与实测效果 | 来源 |

| 训练 | 噪声感知训练（noise-aware training, NAT/HWA） | PCM 上 ResNet 恢复至接近软件精度 [^623^]；VANT 把 CIFAR-10 噪声下精度从 72.3%→97.3%、TinyImageNet 38.5%→89.9% [^625^]；IBM HWA 使 11 个负载归一化精度全部 >96% [^621^] | [^621^][^623^][^625^] |

### 4.4 专家验证：问题 5 预设的判定

#### 4.4.1 结论："LLM 容忍度更高"笼统说法不成立，须分通路回答

对用户问题 5 的预设"相对图片分类等模型，大语言模型对误差容忍度更高"，本报告判定为 **不成立（需按通路修正）**，对应交叉验证冲突区 C4。证据链分三条。其一，权重通路上预设方向成立：经 HWA 训练的 BERT 与全部 LSTM 达 >99% iso-accuracy 而 CNN 最多掉 3.6% [^621^][^622^]，175B 模型 4-bit 权重仅损 ≤0.25 PPL [^601^]——对编程误差/retention 类权重偏移，LLM 容忍度不低于甚至高于 ResNet 类 CNN。其二，激活/KV 通路上预设方向反转：CNN 的 INT8 PTQ 早已解决，LLM 却因 >6.7B 涌现的系统性激活 outlier 使朴素 W8A8 崩溃（71.6%→32.3%）[^604^][^606^]，KV cache 更是 CNN 没有的攻击面，2-bit Key 即崩 [^608^][^609^]。其三，结论依赖评估指标：teacher-forced PPL 显示高容忍，自由长链生成先崩（高熵位置漂移 ρ=0.92 [^612^]、PPL 不变而能力已降 [^628^]），单用 PPL 会系统性低估噪声损伤。综合置信度：中——权重通路证据充分；"激活通路比 CNN 更敏感"有大量量化证据，但缺严格同噪声模型下的头对头对照实验。

另需提示趋势性风险：训练越充分，量化/噪声容忍度越差——QiD 标度律 [^617^]、Scaling Laws for Precision [^618^] 与过训练模型扰动实验 [^619^] 三方独立证据同向；随 SOTA 模型 token/参数比攀升（Llama-3 已达 15T:8B [^617^]），未来 LLM 对低比特与硬件噪声将更敏感，Outlier-Safe Pre-Training 证明 outlier 可从训练配方中消除 [^627^]，是目前唯一的对冲方向。回到调研目的：NAND CIM 的模拟 MAC 噪声（编程误差、retention、读扰动）主要注入权重通路，恰落在容忍度最高的通路上；真正脆弱的激活与 KV 本就不经过 CIM 阵列。因此 NAND CIM 的精度风险可控，设计重点应放在 outlier FP16 冗余、噪声感知训练/LoRA 补偿与 ECC/温补的组合上，而非整体回避模拟计算；验收口径则须以长链推理任务而非 PPL 为准。
