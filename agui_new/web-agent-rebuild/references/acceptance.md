# 按行为验收

只检查本次实现所涉及的路径。使用隔离样例与临时目录；不为验证发送真实邮件、执行审批或改写生产数据。

## 层次

| 层次 | 应证明的内容 | 不能由它替代的内容 |
| --- | --- | --- |
| 静态与接口 | 语法、字段契约、路由、权限依赖和边界 | 真实交互、业务语义 |
| 确定性业务 | 新旧入口同样输入得到同样结果；错误与范围一致 | 模型工具选择质量 |
| 模拟模型/工具 | 请求结构、工具回填、暂停/失败/预算 | 真实端点支持与生成质量 |
| 浏览器 | 实际按钮、状态、字段、焦点、导出与布局 | 并发持久写入正确性 |
| 真实端点 | 授权下的少量调用可达且可用 | 大规模效果、成本与生产稳定性 |

## 按实现选择关键情景

- **既有应用**：重放原主路径和校验错误；检查返回格式、计算口径、登录/租户范围、导出和业务副作用是否回归。
- **语言填写**：不修改未要求字段；建议不自动提交；生成/应用间的人工改动不被覆盖；过期结果显示实际提交范围。
- **候选表单与个性化**：建议来源、更新时间和身份范围与字段对应；多候选的差异可见；缺少数据时不伪装成有依据的推荐。让用户实际改写候选，观察错误和核对成本。
- **探索与收敛**：记录目标、证据、有效步骤和反例。将路径整理为 A 前，重放另一种输入与失败案例；多场景路由含低把握澄清与错路由恢复。
- **工具执行**：确实调用业务函数/脚本，不能仅返回写死成功文本；错误参数、未知工具、跨会话资源、越权范围和已确认条件冲突得到明确处理。
- **任务流**：目标、澄清、继续、成功、超时、模型错误、预算耗尽可区分；真实模式失败不能静默变演示成功。
- **共编产物**：两个同版本写入不能都成功；旧草稿不能覆盖人工修改；dirty editor 不被轮询覆盖；保存期间继续输入仍保留且可再次保存。
- **取消/重启**：取消后迟到结果不再提交；刷新不重复执行；重启状态准确；只恢复可安全重试的步骤，外部写入不重复。
- **身份/展示**：复用已有权限；模型/用户 HTML 作为安全文本或经审定渲染；Key 不进入页面、日志或错误正文。
- **UI**：桌面与窄屏检查长标题、选择器、表格、加载、空态、错误态和键盘导航。查看实际截图，不只数 DOM 元素。

复杂应用如可独立验收，将任务说明、代码/差异、输入数据和规则交给新上下文；不传递预期结论。不能独立验收时明确自测范围，不宣称独立通过。

## 交付记录

用少量证据写明运行命令、已测路径、结果、真实/演示数据和未验证项。不要沿用前一个项目的测试数量或验收结论。本地演示延迟不能当模型性能，界面流畅也不能当任务成功率。发生失败先说明对完成任务的影响和恢复方法。

若要判断收益，A 记录填写、核对、纠错总耗时与原表单对照；B 记录路径复用、例外、路由正确性与完成任务成本。观察数据不足时保持探索性判断，不预设 B 必然收敛到 A。

## 接口边界的类型变化

传统表单参数通常是字符串，新增 JSON/工具入口可能收到 null、布尔值、数组或对象。为请求体及嵌套字段建立明确的类型/枚举/范围校验，再调用既有业务函数；复用函数本身不代表新入口已经受控。至少给核心字段一个错误类型反例，验证返回可理解的 4xx 及可恢复状态，而非未处理的 500。对模型响应的容器和嵌套项也先检查类型；可解析 JSON 不等于协议有效。

## 可组合交互的代表路径（按采用功能选择）

- 上下文对象的显示与实际提交一致；删除/换版本后建议重算或标明失效，越权资源仍由后端拒绝。长粘贴折叠后能查看/恢复原内容。
- 中文组合输入的 Enter 不提交；失败保留草稿；抽屉折叠仍能发现缺条件和错误，键盘焦点不落入不可见区域。
- 流式输出时向上回看不被拉回底部，新内容有提示，主动回到底部可继续跟随。
- 分组内一项失败在摘要可见；展示状态来自后端事件，展开日志不泄露敏感值。
- 在窄嵌入容器及移动端打开/关闭产物，检查断点、焦点返回、草稿保留与阅读位置；若提供调宽，检查键盘及边界。
- 对样例按钮逐项确认是否接入实际行为，不能以版本菜单或成功图标代替保存/执行验收。
