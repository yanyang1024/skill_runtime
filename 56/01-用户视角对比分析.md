# 五大 AI 编程 Agent 用户视角对比分析

> 对比对象：Claude Code（cc）、Codex CLI、opencode、pi、DeepSeek Harness（dsh）
> 视角：**纯使用者**——不关心源码，只关心装什么、怎么用、多少钱、会踩什么坑
> 信息截至：2026-09；实现层结论来自对五家 harness 的源码/文档分析会话记录

| 工具 | 出品方 | 一句话定位 |

| **Claude Code** | Anthropic | 闭源精品店：体验最完整、纵深防御最深，但绑死 Claude 模型 |

## 三、分场景推荐

### 1. 「我就想省心，写业务代码」→ Claude Code
订阅制、不用管 API Key、模型质量天花板、plan 模式和子代理成熟。适合把 AI 编程当生产力工具而非研究对象的人。

### 2. 「我是 ChatGPT 订阅用户 / 要跑无人值守任务」→ Codex CLI
登录即用，OS 级沙箱（macOS Seatbelt / Linux Landlock+seccomp）是五家里最硬的隔离——自动审批跑任务时，这个沙箱就是你买的东西。`/review` 代码评审、`/import` 一键迁移 Cursor/Claude Code 配置也很实用。

### 3. 「我要多模型比价 / 用国产模型 / 跑本地模型」→ opencode
模型无关是它的立身之本：75+ provider、Ollama 本地模型、会话中 `/model` 随时切换。成本敏感时用便宜模型跑简单重构，复杂任务切旗舰模型。隐私场景（代码不出本机）配 Ollama 是唯一零成本方案。

### 4. 「我想把 agent 嵌进自己的系统 / 打造自己的工作流」→ pi
pi 的口号是 "there are many agent harnesses, but this one is yours"。它没有 plan mode、没有子代理、没有权限弹窗——全是扩展。Databricks 内部基准测试里 pi 在 Opus 4.8 上 pass rate 最高、成本显著低于 CC 和 Codex（每轮上下文少约 3 倍），说明极简不是简陋。适合有明确工作流、愿意自己动手的高级用户。

### 5. 「我用 DeepSeek / 做 agent 研究或评测 / 需要强审计」→ dsh
默认 read-only + 内核级沙箱，越权写入得到的是内核拒绝而非"模型礼貌回绝"；append-only 会话日志支持在第 39 步 fork 重跑第 40 步，做失败分析、good/bad case 回放是五家里独一档。PTC 模式（模型写一段程序编排工具调用）缓存命中率可达 99%，跑重复性多步任务 token 成本极低。

### 场景速配表

| 你的情况 | 首选 | 次选 |
|---|---|---|
| 零基础，只想马上用 | Codex CLI（有 ChatGPT）/ Claude Code（愿意订阅） | opencode + Zen |
| 团队成本敏感，模型要灵活 | opencode | dsh（DeepSeek 便宜） |
| 金融/政企代码不能出网 | opencode + Ollama | pi + Ollama |
| CI/CD 无人值守 | Codex CLI（沙箱） | dsh headless（read-only 默认） |
| 自己造轮子/二开 | pi（改扩展） | dsh（换插件）/ opencode（改源码） |
| Agent 评测、行为研究 | dsh（Minimal 模式冻结 harness 变量） | pi（行为可预测） |

## 四、坑点清单（重点，挨个说）

### 共性坑（五家都有）

1. **权限弹窗疲劳**。问多了用户会无脑点 allow——这等于关掉权限系统。正确姿势：把高频安全命令写进 allowlist，让 ask 只出现在真正异常的场合。
2. **"看着对了"的代码**。所有工具都会产出能跑但语义错的代码，git 提交前必须看 diff。在 agent 动手前先 `git commit` 是最便宜的后悔药。
3. **大输出灌爆上下文**。`ls -R`、全量日志、大文件读取会让 agent"变傻"（上下文被垃圾占满）。各家截断能力不同（见下），但用户侧最好的办法是任务描述里就限定范围。
4. **会话越长越蠢**。上下文压缩（compaction）会丢细节，关键状态（迁移进度、决策结论）让 agent 写进文件，别指望它"记得"。

### Claude Code 专属坑

- **闭源 + 服务端 feature flag**：行为可能在同版本间漂移（比如灰度推送"Bash 优先"提示词变体后，它突然不爱用专用工具了）。排查"agent 行为变了"时先怀疑 flag，不是你的配置。
- **订阅凭证不能外带**：2026 年 1 月起 Anthropic 封锁了第三方工具使用 Claude 订阅凭证，想在 opencode/pi 里用 Claude 必须按 token 付费的 API Key。
- **权限规则语法学习成本高**：`"Bash(npm run test *)"` 这种三列表结构，deny > ask > allow 且与具体度无关，写错了不会报错，只是不生效。
- **已知绕过路径**：Read 的 deny 曾被替代工具路径绕过——denylist 不是安全边界，别拿它保护密钥文件，用 hooks 或沙箱。

### Codex CLI 专属坑

- **第三方模型门槛变高**：`wire_api = "chat"` 已被移除，只认 Responses API。很多 OpenAI 兼容网关不支持 Responses，接第三方模型前务必确认。
- **apply_patch 格式是 OpenAI 私有协议**（V4A diff）：换非 OpenAI 模型可能根本不会输出这套格式，编辑直接失败。
- **截断不可逆**：10KB/256 行硬截断、没有落盘回读，日志被截了就真丢了——长日志任务让它自己写文件再分段读。
- **Windows 沙箱弱**：OS 沙箱主要覆盖 macOS/Linux，Windows 上建议跑 WSL。
- **"danger-full-access" 别乱开**：开了等于裸奔。

### opencode 专属坑

- **默认 permissive**：装完不配权限就是全自动放行。务必先写 `permission` 配置（deny 掉 `rm -rf`、越界路径等）。
- **无 OS 沙箱**：权限系统只检查命令字符串，被 allow 的命令名不副实（如脚本里藏 `rm`）照样放行。高风险项目在容器/VM 里跑。
- **Claude 订阅不能用**（同上，Anthropic 封锁），只能 API Key。
- **不同 provider 路径打磨不一**：Claude/GPT 路径很稳，小众模型和本地模型的 tool-calling 质量参差。
- **截断提示可能指向被禁用的工具**：如果你禁用了 Grep/Read，模型会收到"用 Grep 处理"的提示然后死循环——配置禁用时注意连带影响。

### pi 专属坑

- **bash 完全裸奔**：没有任何权限层，命令以你的完整权限执行。**不要**在不隔离的环境里让它跑你不理解的任务；官方建议就是容器化（Docker/Gondolin/OpenShell）。
- **"没有"不是"坏了"**：没有 plan mode、没有子代理、没有权限弹窗是设计选择，需要自己装扩展（`pi install npm:@foo/pi-tools`）或让 pi 给自己写一个。
- **依赖外部二进制**：grep/find 依赖 ripgrep 和 fd，首次使用会自动下载到 `~/.pi/agent/bin/`，离线/受限网络环境会卡。
- **compaction 丢细节**：会话总结时每个工具结果截到 2000 字符，重要状态务必落文件。
- **Windows 支持相对次要**：生态以 macOS/Linux 为主。

### dsh 专属坑

- **v0.1 开发者预览**：README 自己承诺会有 breaking change，别上生产关键链路。
- **`danger-full-access` 预设 = 拆光所有墙**：沙箱和审批一起关，没有第二道防线（不像 CC 还有 hooks）。
- **WSL 有坑**：社区已报告 WSL 下 bash 跑出 Windows ACL 沙箱之外、文件策略不生效。
- **Web UI 只绑 localhost**：远程使用要自己解决代理/SSL/认证。
- **PTC 模式不是安全边界**：`run_code` 的 Worker Thread 官方定义为 "containment, not a security boundary"，信任等级等同 bash。
- **Node 版本挑**：要求 22.19+ 或 24+，奇数版本别赌。
- **插件生态刚起步**：预设之外的插件质量靠社区自觉。
