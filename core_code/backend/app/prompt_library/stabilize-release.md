# stabilize-release 稳定·发布检查

## 阶段说明

发布前的最终检查：结构完整性、frontmatter 合法性、内容一致性、无临时产物。此阶段只检查和出结论，不修改 stable 内容。

## 常用语句

- 请做发布前检查：SKILL.md 的 frontmatter 是否合法、文件结构是否完整、references 引用是否都存在、有没有遗留的临时内容，输出一份发布检查清单。
- 对照发布标准逐项核对当前 Skill：名称规范、描述完整、示例可运行、无调试残留，给出可以发布或需要返工的结论。
- 发布前最后过一遍：确认所有文件内容一致、没有未完成标记、没有过时信息，只输出检查结果，不要修改。
- 帮我确认这个 Skill 是否达到发布状态，如果有阻塞问题请按优先级列出，并说明每个问题的修复方向。
