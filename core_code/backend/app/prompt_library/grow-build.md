## 阶段说明

按照已确认的方案实际修改 Skill 文件。这是可以动手写文件的阶段，改动要符合方案、保持现有风格一致。

## 常用语句

- 按照刚才确认的方案开始修改：先更新 SKILL.md 的触发描述和步骤，再同步调整 references 里的细节，改完后告诉我每个文件改了什么。
- 请实施计划中的第一步，直接修改对应文件，改动保持现有文档的中文风格和目录结构。
- 把我们讨论好的新示例写进 references 目录，并在 SKILL.md 里补上引用，注意示例要可以直接运行。
- 继续执行方案中的剩余改动，每完成一个文件就简要汇报改动内容，全部完成后停下来等我确认。
