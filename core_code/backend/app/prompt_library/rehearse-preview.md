# rehearse-preview 演练·真实体验

## 阶段说明

以真实用户的身份完整体验这个 Skill，走一遍典型使用流程，记录体验中的卡点和落差。重点是体验与反馈，不是改文件。

## 常用语句

- 请扮演一个第一次使用这个 Skill 的用户，严格按照 SKILL.md 的描述走一遍完整流程，记录每一步是否符合预期、哪里会卡住，输出体验报告。
- 我们用真实场景演练一下：我提出一个典型需求，你按 Skill 当前的能力回应，然后我们一起分析回应质量与文档描述之间的差距。
- 模拟用户视角检查这个 Skill：触发词是否自然、步骤是否好懂、输出是否有用？把发现的问题按体验影响排序。
- 假设我是一个挑剔的用户，用这个 Skill 完成一次真实任务，指出过程中所有让我困惑或失望的地方。
