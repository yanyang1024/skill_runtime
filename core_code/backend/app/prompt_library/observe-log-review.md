# observe-log-review 观察·日志复盘

## 阶段说明

复盘已有会话记录、日志和现有文件，搞清楚 Skill 当前的真实状态与问题。此阶段只观察、分析和总结，不修改任何文件。

## 常用语句

- 请通读当前 workspace 里的会话日志和相关文件，梳理这个 Skill 目前的功能边界、最近几轮对话暴露出的问题，以及我反复提到的诉求，最后输出一份现状复盘，不要修改任何文件。
- 帮我复盘一下最近的对话记录：哪些需求已经解决、哪些回答质量不稳定、哪些问题被反复提起？请按严重程度列出清单，先不要动文件。
- 请查看 output 目录下已有的产物，对照我在 notes 里的记录，总结当前进度和遗漏点，只输出结论。
- 回顾一下我们到现在为止的讨论，提炼出对 Skill 改进最有价值的三条观察，并说明依据。
