# rehearse-iteration 演练·迭代改进

## 阶段说明

基于演练中收集的反馈修改 Skill，改完继续演练验证，形成"体验-改进-再体验"的小循环。此阶段可以修改文件。

## 常用语句

- 根据刚才演练发现的问题修改 Skill：优先修复会卡住用户的卡点，改完后说明每处修改对应哪条反馈。
- 请把体验报告里排名前三的问题逐一修掉，修改时保持其他部分不变，完成后我们再演练一轮验证。
- 上一轮演练暴露的触发词问题还没解决，请调整 SKILL.md 的描述让触发更自然，然后用一个新场景验证效果。
- 基于这轮反馈做一轮小步迭代：只改最关键的两处，改完总结改动点，等我确认后再继续。
