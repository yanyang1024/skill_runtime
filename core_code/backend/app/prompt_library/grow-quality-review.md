# grow-quality-review 成长·质量审查

## 阶段说明

检查本轮修改的质量：文件之间是否一致、内容是否过时、是否有冲突或遗漏。此阶段只审查和报告，不直接修改文件。

## 常用语句

- 请做一轮交叉一致性 review：检查 SKILL.md、references、agents 和实际工具文件之间是否存在过时、冲突或未完成的部分，先只生成质量审查结论，不要继续修改文件。
- 确认所有文件的最新状态，检查本轮修改是否完整覆盖了之前提出的问题，列出已解决和未解决的清单。
- 检查这轮改动有没有引入重复规则、过时引用或文件之间的不一致，按严重程度输出审查报告。
- 以挑剔的眼光审查当前 Skill：描述是否清晰、触发条件是否准确、示例是否与实现一致？只给结论和改进建议。
