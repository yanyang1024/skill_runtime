# grow-plan 成长·方案制定

## 阶段说明

基于观察结论制定 Skill 的更新方案：改哪些文件、怎么改、按什么顺序改。此阶段只产出计划，不动手写文件。

## 常用语句

- 基于刚才的复盘结论，制定一份 Skill 更新方案：列出需要修改的文件、每个文件的改动要点和优先级，说明取舍理由，先不要改任何文件。
- 请把接下来的改进拆成可执行的几步，每一步说明目标、涉及文件和验收标准，输出一份实施计划供我确认。
- 针对目前发现的问题，给我一版最小改动的方案和一版彻底重构的方案，对比两者的成本和风险，我来选一个。
- 在动手之前，请先说明 SKILL.md 的 frontmatter、references 目录和示例文件分别要调整什么，以及为什么这样调整。
