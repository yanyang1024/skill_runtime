# observe-api-scan 观察·API 扫描

## 阶段说明

分析 API 文档、端点定义、接口变化和已有测试，找出 Skill 需要适配或覆盖的接口面。此阶段只输出分析结论，不修改文件。

## 常用语句

- 请阅读 files 目录下的 API 文档，列出全部端点、必填参数和响应结构，标注出与 Skill 当前实现不一致或缺失的部分，只输出分析结果，不要修改文件。
- 扫描一下这份 API 规范：哪些端点最近有变更、哪些参数被废弃、哪些错误码需要在 Skill 里处理？请整理成清单形式的结论。
- 请对照 API 文档检查现有测试用例的覆盖情况，指出没有覆盖到的端点和边界场景，先给出清单。
- 分析这份接口文档里的鉴权方式和限流策略，说明 Skill 在调用这些接口时需要注意什么。
