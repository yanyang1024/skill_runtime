# 信号定义与解读边界

每个信号：可确定的观测 / 推理边界 / 分母或排查单位 / 优先验证的改动。

| 信号 | 可确定的观测 / 推理边界 | 分母或排查单位 | 优先验证的改动 |
|---|---|---|---|
| 工具 error（tool_metric_rows） | 记录状态可确定；错误文本分型是规则推理 | error / (success+error)，取消/未知另列 | 错误结构、参数提示、针对特定错误的恢复规则 |
| 同参反复 error（same_tool_after_error_candidate 的 same_args_later_errors） | 同会话同工具、参数完全相同、窗口内再错可确定；"无进展"待判断 | 每个初始错误的窗口；不能把重叠信号相加 | 澄清参数约束、阻止已知无效重复尝试 |
| 错后恢复线索（later_success_observed） | 同工具后来 success；无 issue_id 时不能确认同问题恢复 | 初始错误及观察完整性，另列窗口长度 | 找前后真正改变的条件，再写小规则 |
| read/write/edit（session_file_events） | 工具报告发生的操作；不是磁盘最终状态快照 | 成功/报错分开，按操作计数 | 补 edit 的路径、片段与证据 ID |
| 会话内路径重读 | 同会话相同路径锚点反复读取；不保证同版本/同范围 | 重复读次数 / 可识别路径的成功 read 次数 | 先检查是否读同版本、同 offset/limit，再考虑缓存 |
| 跨会话共享路径（shared_path_candidates） | 已知共享存储下，先修改后另会话读取 | 唯一逻辑路径×消费会话；另列原始事件数 | 选少数知识文件验证"被用到且有帮助" |
| Skill/Agent 接触（capability_contacts） | skill 加载、task 分派及调用状态；不是效果 | 使用会话数、已知用户数，按能力和部门切片 | 检查匹配任务、返回契约、下游验收 |
| question（question_call_review） | 调用发生是观测；必要性与类型需读上下文 | 有 question 的会话 / 已覆盖会话 | 区分必要业务决策和可提前采集的信息 |
| 跨会话重复任务 | 同用户、实体/任务锚点、邻近时间只是候选 | 候选任务家族，不按相似标题计失败数 | 从真实摩擦点抽出回归题 |
| 任务图谱/路由（task_map） | 标签来源与预测分数可记录；场景分类可能错 | 一会话一主任务+可选次任务，unknown 保留 | 找边界任务，试同模型下路由提示补充 |
| shell 可能写文件（shell_possible_write_review） | 命令文本含 `>`/tee/cp/mv 模式；未登记为实际文件变更 | 每条命令人工复盘 | 引号内文本和未执行分支都可能命中，只作线索 |

## 补充口径

- **会话内重读**选定一种定义：例如每会话 `成功 read 数 - 唯一路径锚点数` 作分子。改动后再读也在其中，所以它不是缓存节省量。
- **任务级成功**优先使用明确验收。感谢结尾、文件生成保留为独立采样标志，不相加成完成分数；抽查时也取未触发标志的随机样本。
- **recorded_tool_error** 含已观测的所有 error；已确认测试负例另列。断言元数据全空时不能推断错误非预期。0/0 显示 N/A。
- **信号可以重叠**，条数不是失败次数；窗口内多个初始错误可能共享同一次成功，不当独立"自愈事件"。
- **失败归因**：只归给加载或分派调用本身；加载错误、下游错误共现、验收失败分列。

## 三个分析层次（不要越层断言）

| 层次 | 现在可做 | 暂不直接断言 |
|---|---|---|
| 会话观测 | error 状态、读写/edit 参数、Skill 加载、Agent 分派、时间与实际 usage | 业务完成、用户水平、工具缺陷 |
| Harness 候选 | 反复同参报错、可能重复注入、Skill 选用不合适、记忆冲突线索 | 某项配置一定造成失败 |
| 模型候选 | 同一冻结任务与环境下，更换模型后的质量/资源差异 | 跨部门报错相近所以模型能力不够 |
